About Hacker Apps

Hacker Apps is a focused directory for discovering applications related to cybersecurity, Android security, privacy, network analysis and command-line workflows. The site provides concise descriptions and separates official project websites from download links where available.

Our approach

We aim to make app discovery clearer, not to host or repackage third-party software. App names, trademarks and software belong to their respective owners. Availability, compatibility and licensing can change, so check the linked project source before installing.

Responsible use

Security applications should be used on devices, accounts and networks you own or have explicit permission to test. Listing an application does not endorse unlawful access or misuse.
