About this app

Dolphy is a multi-purpose Android application designed for wireless protocol research, cybersecurity testing and hardware emulation. It brings together tools for working with several wireless technologies, including Bluetooth, Wi-Fi, NFC and infrared (IR).

The application also supports Shizuku integration, allowing compatible features to work through Shizuku without requiring traditional root access. Version 2.6 includes Italian language support.

Key features

  • Cybersecurity testing capabilities
  • Hardware emulation features
  • Bluetooth support
  • Wi-Fi support
  • NFC support
  • Infrared (IR) support
  • Shizuku integration
  • Designed to work without root access
