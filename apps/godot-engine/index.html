Godot Engine

AndroidVersion 4.7.2

An open-source game engine with an editor that lets you create and edit game projects directly on supported Android devices.

About this app

Godot Engine is a free and open-source game engine for building 2D and 3D games. The Android editor brings many project-editing features to mobile devices, allowing developers to work on projects without needing a desktop computer for every task.

For a more comfortable workflow, a physical keyboard and mouse are recommended. Performance and available features depend on the Android device and its hardware.

Key features

  • Create and edit game projects
  • Tools for 2D and 3D game development
  • Open-source development environment
  • Project editing directly on supported Android devices
  • Touchscreen support with improved workflow when using a keyboard and mouse
