Magisk

AndroidOpen source

Magisk is an open-source Android rooting solution that provides systemless modifications, root access management and support for modules.

About this app

Magisk is used to obtain and manage root access on compatible Android devices. It supports systemless modifications and modules that can customize device functionality. Rooting requires technical knowledge and may affect device security, compatibility and warranty coverage.

Key features

  • Systemless root access for compatible Android devices
  • Manage root permissions for installed applications
  • Support for Magisk modules and system customization
  • Open-source project with releases published on GitHub

Safety and responsible use

Rooting changes Android's security model and may cause boot failures, reduce device security or affect banking and payment applications. Back up important data, verify the APK source and follow instructions for your specific device. Never flash files intended for a different device.
