Termux

Android

A terminal emulator and Linux environment for Android, with package management and shell tools.

About this app

Termux provides an Android terminal environment and a Linux package collection. It is useful for command-line workflows, scripting, learning Linux fundamentals and running supported packages on a compatible Android device.

Key features

  • Terminal emulator for Android
  • Package management through APT
  • Supports shell scripting and common command-line workflows
